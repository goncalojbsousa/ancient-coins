> Apresentação prática da implementação de um CRUD utilizando o Supabase numa aplicação Ionic. Inclui os passos essenciais para configurar o projeto, criar a base de dados, desenvolver um service para operações CRUD, criar componentes de apoio e construir o interface necessário para interação com os dados armazenados no _Supabase_.

# Supabase

1. Criar uma conta no [Supabase](https://supabase.com/);
2. Criar um novo projeto em **New Project** e seguir as instruções para a criação de um novo projeto;
3. Aceder ao **SQL Editor** (_barra lateral do lado esquerdo_) e executar o seguinte _script_;

    ```sql
    create table public.alunos (
      id bigint generated by default as identity primary key,
      nome text not null,
      curso text not null,
      created_at timestamptz default now()
    );
    ```

4. Ativar o Row Level Security (RLS) e criar políticas de acesso para efeitos de demonstração/aula:

    ```sql
    alter table public.alunos enable row level security;

    create policy "Permitir leitura anonima para aula"
    on public.alunos
    for select
    to anon
    using (true);

    create policy "Permitir insercao anonima para aula"
    on public.alunos
    for insert
    to anon
    with check (true);

    create policy "Permitir atualizacao anonima para aula"
    on public.alunos
    for update
    to anon
    using (true)
    with check (true);

    create policy "Permitir remocao anonima para aula"
    on public.alunos
    for delete
    to anon
    using (true);

    grant usage on schema public to anon;
    grant select, insert, update, delete on table public.alunos to anon;
    grant usage, select on all sequences in schema public to anon;
    ```

    > **NOTA IMPORTANTE**  
    > As políticas acima são adequadas apenas para demonstração em aula, porque permitem operações CRUD sem autenticação. Numa aplicação real, devem ser usadas políticas associadas a utilizadores autenticados e regras de autorização mais restritivas.

ou

5. Aceder ao **Table Editor** (_barra lateral do lado esquerdo_) e à opção **Create table**;
6. Criar uma tabela chamada `alunos` com as colunas `id`, `nome`, `curso` e `created_at` (ver tipos de dados acima);
7. Ativar o **Row Level Security** e criar as políticas necessárias para permitir o acesso pretendido;
8. Aceder a **Project Settings** (_barra lateral do lado esquerdo_);
9. Aceder à opção **Data API** e copiar o valor de **API URL** (sem a parte do rest/v1/, ou seja, https://xxxxxxxxxxxx.supabase.co);
10. Aceder à opção **API Keys** e copiar o valor de **Publishable key**, na secção **Publishable key**.

> A **Publishable key** pode ser usada em aplicações web/mobile porque é uma chave pública. Não deve ser usada uma **Secret key** no código da aplicação, porque essa chave é privada e deve ficar apenas em ambientes de servidor.


# Preparar a app

1. Criar a app

    ```bash
    ionic start exemplosupabase blank --type=angular
    ```

2. Entrar na pasta do projeto Ionic e instalar o _package_ `@supabase/supabase-js`

    ```bash
    npm install @supabase/supabase-js
    ```

    Este package permite operações sobre a base de dados, autenticação de utilizadores, upload/download de ficheiros, realtime, entre outras funcionalidades do Supabase.

3. Atualizar o ficheiro `src/environments/environment.ts` com as configurações públicas do projeto Supabase:

    ```typescript
    export const environment = {
      production: false,
      supabaseUrl: 'https://url_do_projeto.supabase.co',
      supabasePublishableKey: 'sb_publishable_key_exemplo'
    };
    ```

    > Estes valores são usados pelo frontend. A chave deve ser a **Publishable key**, nunca uma **Secret key**.

# Desenvolver um Service

1. Criar um service para gerir as operações CRUD com o Supabase:

    ```bash
    ionic g service services/supabase
    ```

2. Criar o ficheiro `aluno.ts` (`\src\app\services\aluno.ts`) que servirá de apoio ao desenvolvimento do Service. Este ficheiro poderá ficar dentro da pasta `services` e apenas contém a definição do `interface` Aluno:

    ```typescript
    export interface Aluno {
      id?: number;
      nome: string;
      curso: string;
      created_at?: string;
    }
    ```

    > Em TypeScript, a interrogação `?` após o nome de uma propriedade indica que ela é opcional. Portanto, a declaração `id?: number;` significa que o interface pode ter uma propriedade chamada `id`, que é do tipo `number`, mas que não é obrigatória. Isto é útil porque o `id`, na base de dados, é incremental e automático, logo não é necessário especificá-lo numa operação de `INSERT`.

3. Criar um módulo para o SupabaseClient

   _Pode ser criado na mesma pasta dos `services`_

    Criar um ficheiro com o nome `supabase.client.ts`, com o seguinte conteúdo (para garantir que seja criada uma única instância do _client_):

    ```typescript
    import { createClient, SupabaseClient } from '@supabase/supabase-js';
    import { environment } from '../../environments/environment';

    let client: SupabaseClient;

    export function getSupabase(): SupabaseClient {
      if (!client) {
        client = createClient(
          environment.supabaseUrl,
          environment.supabasePublishableKey,
          {
            auth: {
              persistSession: true,
              autoRefreshToken: true,
              detectSessionInUrl: false,
            }
          }
        );
      }

      return client;
    }
    ```

4. Desenvolver o código necessário para as quatro operações (**C**reate, **R**ead, **U**pdate e **D**elete) sobre a base de dados previamente criada no Supabase em `\src\app\services\supabase.ts`

    ```typescript
    import { Injectable } from '@angular/core';
    import { SupabaseClient } from '@supabase/supabase-js';
    import { getSupabase } from './supabase.client';
    import { Aluno } from './aluno';

    @Injectable({
      providedIn: 'root'
    })
    export class SupabaseService {

      private supabaseClient: SupabaseClient;

      constructor() {
        this.supabaseClient = getSupabase();
      }

      async getAlunos(): Promise<Aluno[]> {
        const { data, error } = await this.supabaseClient
          .from('alunos')
          .select('*')
          .order('nome', { ascending: true });

        if (error) {
          throw error;
        }

        return data as Aluno[];
      }

      async getAlunoById(id: number): Promise<Aluno> {
        const { data, error } = await this.supabaseClient
          .from('alunos')
          .select('*')
          .eq('id', id)
          .single();

        if (error) {
          throw error;
        }

        return data as Aluno;
      }

      async insertAluno(aluno: Omit<Aluno, 'id' | 'created_at'>): Promise<Aluno> {
        const { data, error } = await this.supabaseClient
          .from('alunos')
          .insert(aluno)
          .select()
          .single();

        if (error) {
          throw error;
        }

        return data as Aluno;
      }

      async updateAluno(aluno: Aluno): Promise<Aluno> {
        const { data, error } = await this.supabaseClient
          .from('alunos')
          .update({
            nome: aluno.nome,
            curso: aluno.curso
          })
          .eq('id', aluno.id)
          .select()
          .single();

        if (error) {
          throw error;
        }

        return data as Aluno;
      }

      async deleteAluno(id: number): Promise<void> {
        const { error } = await this.supabaseClient
          .from('alunos')
          .delete()
          .eq('id', id);

        if (error) {
          throw error;
        }
      }

    }
    ```

    > Nas operações `insert` e `update`, o método `.select()` é necessário caso seja pretendido receber de volta o registo criado/atualizado.

# Desenvolver um Component
## _passo opcional, mas recomendado_

1. Criar um component que servirá para confirmação de operações, permitindo a resposta de confirmação "Sim/Não" em operações críticas, como por exemplo a eliminação de um registo.

    ```bash
    ionic g component ConfirmModal
    ```

2. Desenvolver o código necessário para o efeito pretendido. Note-se que o código é genérico o suficiente para receber um título e uma mensagem, logo pode ser utilizado em situações distintas. O código é desenvolvido no ficheiro, que resulta do comando acima, `\src\app\confirm-modal\confirm-modal.component.ts`

    ```typescript
    import { Component, Input } from '@angular/core';
    import { ModalController } from '@ionic/angular';

    @Component({
      selector: 'app-confirm-modal',
      template: `
        <ion-header>
          <ion-toolbar>
            <ion-title>{{ title }}</ion-title>
            <ion-buttons slot="end">
              <ion-button (click)="fecharModal(false)">Não</ion-button>
              <ion-button (click)="fecharModal(true)">Sim</ion-button>
            </ion-buttons>
          </ion-toolbar>
        </ion-header>
        <ion-content>
          <div class="ion-padding">{{ message }}</div>
        </ion-content>
      `,
      standalone: false
    })
    export class ConfirmModalComponent {

      @Input() message = '';
      @Input() title = '';

      constructor(private modalController: ModalController) {}

      async fecharModal(resposta: boolean): Promise<void> {
        await this.modalController.dismiss(resposta);
      }

    }
    ```

# Construir o interface para interação com a base de dados

## Considerações iniciais:

1. O **CRUD** pode ser implementado em ecrãs distintos, não obstante, neste caso em particular, foi totalmente desenvolvido no componente `home.page.ts` e no template que lhe corresponde `home.page.html`, para efeitos de simplificação da demonstração.

2. No caso de não haver a utilização de um qualquer _component_ criado para determinada finalidade, e apenas ser pretendida a interação com a base de dados Supabase, não há necessidade de qualquer configuração, quer ao nível da app, quer ao nível do component `home.page`.

3. Por outro lado, se quisermos utilizar, por exemplo, o _component_ `confirm-modal.component`, é necessária a seguinte configuração em `\src\app\home\home.module.ts` (ou no ecrã que dele faça uso):

    - Importar o _component_:

      ```typescript
      import { ConfirmModalComponent } from '../confirm-modal/confirm-modal.component';
      ```

    - E em `@NgModule` adicioná-lo ao array `declarations`. O referido array ficará como mostrado de seguida:

      ```typescript
      declarations: [HomePage, ConfirmModalComponent]
      ```

## Exemplo de `home.page.ts`

```typescript
import { Component, QueryList, ViewChildren } from '@angular/core';
import { IonItemSliding, ModalController, ViewWillEnter } from '@ionic/angular';
import { Aluno } from '../services/aluno';
import { SupabaseService } from '../services/supabase';
import { ConfirmModalComponent } from '../confirm-modal/confirm-modal.component';

@Component({
  selector: 'app-home',
  templateUrl: 'home.page.html',
  styleUrls: ['home.page.scss'],
  standalone: false
})
export class HomePage implements ViewWillEnter {

  @ViewChildren(IonItemSliding) slidingItems!: QueryList<IonItemSliding>;

  alunos: Aluno[] = [];
  aluno: Aluno = {
    nome: '',
    curso: ''
  };

  novoAluno = false;
  editarAluno = false;
  modalTitle = '';
  isLoadingAlunos = false;
  errorMessage = '';
  private hasShownSlidingHint = false;

  constructor(
    private supabaseService: SupabaseService,
    private modalController: ModalController
  ) {}

  async ionViewWillEnter(): Promise<void> {
    await this.getAlunos();
  }

  async getAlunos(): Promise<void> {
    this.isLoadingAlunos = true;
    this.errorMessage = '';

    try {
      this.alunos = await this.supabaseService.getAlunos();
    } catch (error) {
      console.error(error);
      this.errorMessage = 'Não foi possível carregar os alunos.';
    } finally {
      this.isLoadingAlunos = false;
      this.showSlidingHint();
    }
  }

  novoAlunoForm(): void {
    this.aluno = {
      nome: '',
      curso: ''
    };
    this.novoAluno = true;
    this.editarAluno = false;
    this.modalTitle = 'Novo Aluno';
  }

  editarAlunoForm(aluno: Aluno): void {
    this.aluno = { ...aluno };
    this.editarAluno = true;
    this.novoAluno = false;
    this.modalTitle = `Editar aluno - ${this.aluno.nome} -`;
  }

  async setAluno(): Promise<void> {
    if (!this.aluno.nome.trim() || !this.aluno.curso.trim()) {
      return;
    }

    if (this.novoAluno) {
      await this.supabaseService.insertAluno({
        nome: this.aluno.nome,
        curso: this.aluno.curso
      });
    } else if (this.editarAluno && this.aluno.id) {
      await this.supabaseService.updateAluno(this.aluno);
    }

    await this.getAlunos();
    this.fecharForms();
  }

  async removerAluno(aluno: Aluno): Promise<void> {
    if (!aluno.id) {
      return;
    }

    const modal = await this.modalController.create({
      component: ConfirmModalComponent,
      componentProps: {
        title: 'Confirmação',
        message: `Tem certeza que deseja remover ${aluno.nome}?`,
      },
      breakpoints: [0, 0.3, 0.5, 0.8],
      initialBreakpoint: 0.3
    });

    await modal.present();

    const { data } = await modal.onWillDismiss<boolean>();
    if (data) {
      await this.supabaseService.deleteAluno(aluno.id);
      await this.getAlunos();
      this.fecharForms();
    }
  }

  fecharForms(): void {
    this.novoAluno = false;
    this.editarAluno = false;
    this.aluno = {
      nome: '',
      curso: ''
    };
    this.modalTitle = '';
  }

  private showSlidingHint(): void {
    if (this.hasShownSlidingHint) {
      return;
    }

    setTimeout(async () => {
      const slidingItem = this.slidingItems?.first;

      if (!slidingItem) {
        return;
      }

      this.hasShownSlidingHint = true;
      await slidingItem.open('end');

      setTimeout(() => {
        slidingItem.close();
      }, 500);
    }, 500);
  }

}
```

**Nota sobre o código:**

No método `removerAluno` na parte do código do `modal`, mais precisamente na linha:

```typescript
const { data } = await modal.onWillDismiss<boolean>();
```

`{ data }` corresponde a uma **atribuição via desestruturação** - _destructuring assignment_.

Sem desestruturação seria:

```typescript
const result = await modal.onWillDismiss<boolean>();
const data = result.data;
```

## Exemplo de `home.page.html`

```html
<ion-header>
  <ion-toolbar>
    <ion-title>
      Alunos
    </ion-title>
    <ion-buttons slot="end">
      <ion-button (click)="novoAlunoForm()">Novo</ion-button>
    </ion-buttons>
  </ion-toolbar>
</ion-header>

<ion-content>
  <ion-card>
    @if (isLoadingAlunos) {
      <ion-list>
        <ion-item>
          <ion-label color="primary">A carregar alunos...</ion-label>
          <ion-spinner name="circles" color="primary"></ion-spinner>
        </ion-item>
      </ion-list>
    } @else {
      @if (errorMessage) {
        <ion-list>
          <ion-item>
            <ion-label color="danger">{{ errorMessage }}</ion-label>
          </ion-item>
        </ion-list>
      } @else {
        <ion-list>
          @for (aluno of alunos; track aluno.id) {
            <ion-item-sliding>
              <ion-item>
                <ion-label>{{ aluno.nome }}</ion-label>
                <ion-note slot="end">{{ aluno.curso }}</ion-note>
              </ion-item>
              <ion-item-options side="end">
                <ion-item-option color="warning" (click)="editarAlunoForm(aluno)">
                  <ion-label class="ion-text-center">
                    <ion-icon name="create"></ion-icon>
                    <div>Editar</div>
                  </ion-label>
                </ion-item-option>
                <ion-item-option color="danger" (click)="removerAluno(aluno)">
                  <ion-label class="ion-text-center">
                    <ion-icon name="trash"></ion-icon>
                    <div>Remover</div>
                  </ion-label>
                </ion-item-option>
              </ion-item-options>
            </ion-item-sliding>
          } @empty {
            <ion-item>
              <ion-label>Não existem alunos registados.</ion-label>
            </ion-item>
          }
        </ion-list>
      }
    }
  </ion-card>

  @if (editarAluno || novoAluno) {
    <ion-card>
      <ion-card-header>
        <ion-card-subtitle>{{ modalTitle }}</ion-card-subtitle>
      </ion-card-header>

      <ion-item>
        <ion-input
          label="Nome"
          label-placement="floating"
          fill="outline"
          [(ngModel)]="aluno.nome"
          required>
        </ion-input>
      </ion-item>

      <ion-item>
        <ion-input
          label="Curso"
          label-placement="floating"
          fill="outline"
          [(ngModel)]="aluno.curso"
          required>
        </ion-input>
      </ion-item>

      <ion-item>
        <ion-button expand="full" (click)="setAluno()">Guardar</ion-button>
      </ion-item>
    </ion-card>
  }
</ion-content>
```

> A sintaxe `@if` e `@for` é a sintaxe atual do Angular para condições e ciclos nos templates. Em versões anteriores era comum utilizar `*ngIf` e `*ngFor`.
