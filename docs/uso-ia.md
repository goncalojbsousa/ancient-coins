# Uso de IA

1. Foi utilizada IA para a criação do ficheiro `seed-data.json`, com dados de exemplo para utilizadores, moedas, conversas e avaliações.

2. Foi utilizada IA para rever código, esclarecer dúvidas técnicas e identificar melhorias durante o desenvolvimento.

3. Foi utilizada IA na criação e revisão do ficheiro `supabase-setup.sql`, incluindo estrutura das tabelas, permissões, Row Level Security, policies e triggers.

4. Foi utilizado apoio de IA na implementação do sistema de mensagens, nomeadamente no sistema de notificações e na atualização dinâmica da página para receber novas mensagens.

5. Foi utilizado apoio de IA na implementação do bucket `coin-images` no Supabase Storage e das respetivas policies de acesso.

6. Foi utilizado apoio de IA para adicionar upload de imagens das moedas, permitindo escolher ficheiro ou tirar fotografia no momento nos modais de adicionar e editar moeda.

7. Foi utilizado apoio de IA para resolver problemas de execução em dispositivo Android, nomeadamente configuração de Java/Gradle e utilização do Capacitor.

8. O código gerado ou sugerido por IA foi revisto, adaptado e integrado manualmente no projeto, mantendo a estrutura e os requisitos definidos pela equipa.
